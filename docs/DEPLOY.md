# Deploying Outreach

Nothing is deployed yet — this is the recipe for when the team needs remote access.
The app is a plain Laravel 13 site: PHP 8.3, MySQL/MariaDB, a web server, no queue
worker, no cron. It runs comfortably next to other Laravel apps on the shared Hostinger VPS.

## Requirements
- PHP 8.3 with `fileinfo`, `mbstring`, `openssl`, `curl`, `intl`, `pdo_mysql`
- MySQL 8 / MariaDB 10.6+
- Composer 2, Node 20+ (build step only — you can also build locally and upload `public/build`)
- HTTPS (Caddy auto-TLS or nginx + certbot). Google OAuth refuses plain http on a public host.
- Outbound TCP 465/587 (SMTP) and 443 (Gmail API, Anthropic API) from the server.

## First install
```bash
git clone <repo> /var/www/outreach && cd /var/www/outreach
composer install --no-dev --optimize-autoloader
cp .env.example .env
php artisan key:generate           # APP_KEY — back it up (see below)
# edit .env: APP_ENV=production APP_DEBUG=false APP_URL=https://outreach.example.com
#            DB_*, SESSION_SECURE_COOKIE=true, GOOGLE_*, ANTHROPIC_API_KEY, SMTP_CAFILE= (empty on Linux)
php artisan migrate --force
npm ci && npm run build            # or upload public/build from a local build
php artisan storage:link           # not needed: attachments are served through the app, never the web root
php artisan config:cache && php artisan route:cache && php artisan view:cache
php artisan outreach:admin you@example.com --name="Jawad"   # prints the one-time password
```
Web root is `public/`. Give the web user write access to `storage/` and `bootstrap/cache/`.

### php.ini
```
upload_max_filesize = 16M
post_max_size = 32M
max_execution_time = 120     ; AI generation batches
memory_limit = 256M
```

### nginx location for uploads
Attachments live in `storage/app/private/attachments` and are streamed by
`/attachments/{id}/download` after auth. Never expose `storage/` directly.

## Google OAuth on the live domain
Add `https://outreach.example.com/oauth/google/callback` to the OAuth client's
authorised redirect URIs (both local and production URIs can coexist), set
`GOOGLE_REDIRECT_URI="${APP_URL}/oauth/google/callback"`, then `php artisan config:cache`.
Gmail mailboxes connected locally keep working after the move — tokens live in the database.

## Updating
```bash
cd /var/www/outreach
git pull
composer install --no-dev --optimize-autoloader
php artisan migrate --force
npm ci && npm run build
php artisan config:cache && php artisan route:cache && php artisan view:cache
```

## Backups — read this one
- **`APP_KEY` in `.env` encrypts every mailbox credential and Gmail token.** Losing it means
  reconnecting every account; keep a copy of `.env` somewhere safe.
- Nightly: `mysqldump outreach > outreach-$(date +%F).sql` and an rsync of `storage/app/private`.

## Operational notes
- No queue worker: sends are synchronous, AI drafts are generated by the browser calling the
  server in small batches. If you ever want background generation, `GenerationRunner::run()`
  is self-contained and can be dispatched from a scheduled `queue:work --stop-when-empty`.
- `pending` sends older than 10 minutes are swept to `unknown` automatically on the next send.
- Logs: `storage/logs/laravel.log` (send failures are logged at warning level with the log row id).
- Health check: `GET /up`.
