# Deploying Outreach

**Live since 2026-09-02 at <https://outreach.staffvora.com>** on the shared Hostinger VPS
(`2.24.11.90`, Ubuntu 24.04, nginx 1.24, PHP 8.3 FPM, MySQL 8, Node 22, certbot). The same box
runs staffvora.com, books.sparkingasia.com and gymrun.tech — every change here must be additive,
`nginx -t` before any reload, `reload` never `restart`.

## Server layout
| What | Where |
|---|---|
| Code | `/var/www/outreach` (root-owned; `storage/` and `bootstrap/cache/` owned by `www-data`, 775) |
| Env | `/var/www/outreach/.env` — `root:www-data`, mode **640** (600 makes PHP-FPM 500 with a misleading "missing app key" error) |
| Database | MySQL `outreach`, user `outreach@localhost` (password only in `.env`) |
| Web | `/etc/nginx/sites-available/outreach.staffvora.com` (symlinked in `sites-enabled`), PHP-FPM socket `/run/php/php8.3-fpm.sock` |
| TLS | Let's Encrypt via `certbot --nginx`, auto-renewal timer; http → https redirect |
| PHP limits | `public/.user.ini` (upload 16M, post 32M, execution 120s, memory 256M) — per-site, the global php.ini is untouched |
| Uploads | `storage/app/private/attachments`, served only through `/attachments/{id}/download` |
| First admin | created with `php artisan outreach:admin`; the one-time password was written to `/root/outreach-credentials.txt` (mode 600) — read it, log in, change it, delete the file |

No queue worker, no cron: sends are synchronous and AI drafts are generated by the browser in
small batches. DNS needs nothing — `*.staffvora.com` already points at the VPS.

## Redeploy (from a local checkout, over SSH)
```powershell
# local: tests green, build not required (the server builds), commit + push
git -C C:\laragon\www\outreach archive --format=tar.gz --prefix=outreach/ -o $env:TEMP\outreach-release.tgz HEAD
scp $env:TEMP\outreach-release.tgz root@2.24.11.90:/root/
```
```bash
# server
cd /var/www && tar xzf /root/outreach-release.tgz -C /var/www && cd outreach
composer install --no-dev --optimize-autoloader --no-interaction
npm ci && npm run build
php artisan migrate --force          # never automatic
php artisan optimize                 # rebuilds config/route/view caches (re-run after ANY .env edit)
chown -R www-data:www-data storage bootstrap/cache
rm /root/outreach-release.tgz
curl -s -o /dev/null -w '%{http_code}\n' https://outreach.staffvora.com/login   # expect 200
```
`git archive` only ships committed files, so `.env`, `vendor/`, `node_modules/` and
`public/build/` never leave the machine; the extract overwrites code and leaves `.env` and
`storage/` alone.

Alternative once a read-only deploy key for `github.com/jawadislam92/outreach` is installed on
the server: `cd /var/www/outreach && git pull && …` (same steps from `composer install` down).

## Changing configuration on the server
Edit `/var/www/outreach/.env` (e.g. `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`,
`ANTHROPIC_API_KEY`), then **`php artisan config:cache`** — the config cache is what PHP reads.
Admin → Settings → "Server setup" shows green ticks once the values are picked up.

## Google OAuth on the live domain
Register `https://outreach.staffvora.com/oauth/google/callback` as an authorised redirect URI on
the OAuth client (the local `http://localhost:8000/...` one can stay). `GOOGLE_REDIRECT_URI` in
`.env` derives from `APP_URL`, so nothing else changes.

## Backups — read this one
- **`APP_KEY` in `.env` encrypts every mailbox credential and Gmail token.** Losing it means
  reconnecting every account; keep a copy of `.env` somewhere safe (it is not in git).
- Nightly: `mysqldump outreach > /root/backups/outreach-$(date +%F).sql` and an rsync of
  `/var/www/outreach/storage/app/private`.

## Health & logs
- `GET /up` → 200.
- `storage/logs/laravel-YYYY-MM-DD.log` (daily channel, warning level; send failures include the log row id).
- `pending` sends older than 10 minutes are swept to `unknown` on the next send.
